# Planning record

This branch holds the planning history for this repo: one folder per issue
under `issues/` (decisions, plan, reviews), saved investigations, and reviews
of other people's work. It shares no history with the code branches.

It is maintained by the Claude Code skills in `~/.claude` (`/planner`,
`/builder`, `/review`, `/issues`) through `~/.claude/lib/planner.py`.
`INDEX.md` is regenerated on every save; `log.md` is append-only.
