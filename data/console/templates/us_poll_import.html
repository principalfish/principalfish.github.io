Import US Polls from Wikipedia

Reads the chosen contests' Wikipedia pages, cross-references every poll against the database, then walks you through the missing ones race by race. Polls already imported never reach the queue. At the end each Senate and House race is pointed at its lead matchup (manual overrides stand), and the US models and the export run once.

Reading every page takes 20–40 seconds. The queue is held in memory while the console runs, so restarting the server — including the automatic reload after any code change — discards an import in progress.
